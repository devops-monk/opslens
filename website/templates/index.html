From a sentence to a safe run.

Every step is plain text you can read, diff and keep in git.

Find

Describe what you want. opslens splits it into data and action, and finds the exact tables, columns and pipelines. Offline, instant, no AI.

Review

A small spec becomes a Flowpipe mod. Validate it, then preview what a run would do right now: how many items, which actions, which values. Nothing executes.

Approve

Deploy only the exact spec hash you reviewed. Anything that changes state waits for a human answer in Slack, Teams or the terminal.

Safe by construction.

The model never writes pipeline code, and nothing destructive runs without a yes.

🛡

Read-only by default

Queries pass a guard: one SELECT, tables from the catalog, a timeout and a row cap, on a read-only connection.

✋

Approval for changes

Pipelines are classed read notify or change. A change must sit behind an approval step, or the spec is refused.

🔍

Reviewed means deployed

Deploy needs the spec hash you approved. Edit a generated file by hand and validation catches the drift.

📓

Everything on the record

An append-only audit log keeps who approved which spec, every deploy, every run and every answer.
